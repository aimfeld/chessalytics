## The landmine this plan exists around

`TrainScheduleSettings`'s debounced draft fires a PUT 600ms after **any** draft
change, independent of what caused it. If toggle-ON wrote
`reminderEnabled: true` into the draft synchronously (the way the weekday chips
write), the PUT could land before the permission prompt resolves, persisting
`reminder_enabled = true` with no live subscription — the silent-lie state D-06
exists to rule out. Toggle-ON is therefore the one asynchronous exception
(D-09); toggle-OFF and hour changes ride the existing debounce unchanged. This
is a documented exception, not an inconsistency to "fix".
