<objective>
Stop a filler-only Train session from masquerading as a normal one: label it, persist that
label so it survives a resume, and make sure it actually accrues streak.

Purpose: with plan 01's honest sharp/herring mix in place, the remaining half of the phase
defect is what the user is TOLD. The label must be server-computed and frozen at composition
(a flag recomputed from current pool state would silently shed itself the moment the ES
lottery lands mid-session), it must never be derived from "is this their first session", and
it is a silent no-op unless `pool_eligible_since` is also stamped for filler-only sessions —
that watermark is the floor `tick_days` reads, so with it NULL a warm-up user accrues no
streak at all regardless of what the UI says.

Output: `drill_sessions.is_warmup` written and read, `TrainSessionResponse.is_warmup` on the
wire, the widened `pool_eligible_since` stamp with its mutation test, and the `'warmup'`
landing kind on the Train start screen replacing the now-dead `'short'` kind.
</objective>
