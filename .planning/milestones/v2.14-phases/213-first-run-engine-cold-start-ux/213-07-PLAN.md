<objective>
Gate the analysis board behind the same modal as Bots, and delete the per-card
download readouts entirely.

Phase 213 shipped the opposite design: the analysis board was deliberately never
gated (it has no clock), and download progress was rendered inline in three
`EngineLinesSkeleton` slots plus the Maia chart's own skeleton. In UAT the user
found those readouts disagreed with each other, one stuck below 100%, and there
were long stretches of downloading with nothing shown at all — and locked the
reversal after declining a dismissible-gate counter-proposal.

One gate, one code path, one place progress is ever shown.

Purpose: G-213-34.
Output: `EngineReadyGate` mounted on the analysis board with a `surface` prop; the
`assetProgress` plumbing, the shared readout formatter and the Maia chart's store
read all deleted along with the tests that lock them.
</objective>

the readouts removed the symptom; only this check proves it was not also the cause.
