<objective>
Bring `build_flaw_filter_clauses` inside the branch limit with a single well-chosen
extraction, and record `fetch_flaw_comparison` as a reasoned logic-LOC exemption instead of
splitting a function that is long in lines but not in logic.

Purpose: this file is the phase's clearest test of judgement. `build_flaw_filter_clauses`
(cognitive complexity 39, the highest in the file despite modest length) is a chain of five
tiny OR-within-family clause builders plus one substantially larger tactic block; extracting
all six would produce five near-trivial single-caller helpers — exactly the "split to fit a
signature" anti-pattern the ROADMAP forbids. `fetch_flaw_comparison` is 284 raw lines but a
single `select()` statement, and no ruff rule flags it: splitting it would trade a readable
column list for an unreadable one.

Output: one named tactic-clause helper, one documented LOC exemption, the file's
`per-file-ignores` entry deleted, and identical SQL for every filter combination.
</objective>
