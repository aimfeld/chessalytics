<objective>
Give the LLM prompt assembler a real byte-level oracle, then split it and the four other
ruff-flagged render blocks along the stage boundaries the author already named in their own
docstrings.

Purpose: `_assemble_user_prompt` is the single worst function in the phase by cognitive
complexity (48) and its docstring already enumerates its filter stages by letter — A2, C2, C3,
C4, C5, C6 — so the seams are documented, not inferred. But the file's tests assert on
substrings of the prompt, which cannot catch a reordered section, a dropped blank line, or a
filter applied one stage too early. A characterization golden captured BEFORE the split closes
that gap, which is exactly the ROADMAP's "tests may be ADDED where a split exposes an untested
seam".

Output: a committed golden prompt plus its equality test; `_assemble_user_prompt` and the four
other flagged functions inside their thresholds and at depth 4 or less; the file's
`per-file-ignores` entry deleted; identical prompt text.
</objective>
