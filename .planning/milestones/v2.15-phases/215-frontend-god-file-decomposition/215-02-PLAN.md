Split `createWorkerPool()`'s 18 inner closures into four sibling stage modules so the factory
drops from 418 counted lines to at most 200, with the existing 109-test suite proving the
worker protocol is byte-for-byte unchanged.

`markPoolFailed`, `progressPort wiring` and `shared Stockfish wasm source`, i.e. the four
things a from-scratch characterization test would have had to cover. No parallel test suite is
to be written; extend that file only where a mutation proof exposes a real gap.

`workerPoolLifecycle.ts`; `createWorkerPool` reduced to state, the two pool-bookkeeping
functions, `whenReady`, the operation wiring and the unchanged return literal; a recorded
two-way mutation proof.
