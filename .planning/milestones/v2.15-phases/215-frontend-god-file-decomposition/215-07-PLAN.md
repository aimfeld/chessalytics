16 tests in `Openings.statsBoard.test.tsx` do not merely cover "the stats board only" — that
file never mounts `OpeningsPage` at all; it renders `getBoardContainerClassName` from

`OpeningsPage`. So the page currently has ZERO render coverage, and the ROADMAP's mandate to
write a characterization test BEFORE splitting is not a formality here: it is the entire
oracle.

`ToggleGroup` plus `<FilterPanel>` block whose props are byte-identical and whose testids differ
only by a `-sidebar` suffix. `frontend/CLAUDE.md`'s "search for duplicated markup before
considering a change complete" rule is written for exactly this shape.

`OpeningsMobileDrawers.tsx` and `useOpeningsChartData.ts` under `src/pages/openings/`;
