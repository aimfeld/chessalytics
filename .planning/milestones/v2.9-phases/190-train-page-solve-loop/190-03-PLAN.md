<objective>
Make Train reachable and discoverable from every nav surface, on the same import gate as Openings and Endgames.

This plan wires the `/train` route created by the tracer into `NAV_ITEMS`, `BOTTOM_NAV_ITEMS`, `ROUTE_TITLES`, `isActive`, and the first-visit notification-dot chain, and extends the app-level nav test that exists precisely because this lock rule is duplicated across three surfaces with historically divergent clause lists.

Purpose: NAV-01 and NAV-02 are the requirements most likely to be half-done — patched on the desktop header and missed on the drawer. The existing `App.test.tsx` was written for exactly that failure mode; extending it is the deliverable, not an afterthought.

Output: a Train tab on three surfaces, correctly gated, correctly ordered, with a chained first-visit dot and regression tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client-side route gate → protected page | `ImportRequiredRoute` / `isNavLocked` are UX affordances on the browser side; the real boundary is the server's auth + guest gate |
| localStorage → nav render | The first-visit flag is user-writable client state read on every nav render |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-190-09 | Elevation of Privilege | Client-side nav lock treated as an access control | low | mitigate | The nav lock and `ImportRequiredRoute` are UX only. Real enforcement stays server-side: `/train/*` sits inside `ProtectedLayout` (authenticated) and every Train endpoint calls the Phase 189 `_reject_guest` 403 gate. This plan adds no client-side check that any server route relies on. |
| T-190-10 | Tampering | `FLAG_TRAIN_VISITED` in localStorage | low | accept | The flag only decides whether a decorative discovery dot renders. A user editing it affects nothing but their own dot; no authorisation or data access depends on it. The hook already fails closed to `false` when localStorage throws. |
| T-190-11 | Information Disclosure | Nav entry visible to users with no Train data | low | accept | The tab's existence discloses nothing beyond the feature's existence, which is public product surface; the gated state is the documented, intended affordance (NAV-02). |
| T-190-SC | Tampering | npm/pip/cargo installs | low | accept | Zero new packages this phase; `lucide-react` is already a direct dependency. No install task exists. |
