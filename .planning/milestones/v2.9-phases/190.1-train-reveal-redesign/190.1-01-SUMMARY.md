# Phase 190.1 Plan 01: End-to-End Played-in-Game Engine Line Summary

**Tracer slice wiring the reveal's game move end-to-end — Postgres-backed SAN→UCI derivation behind the 409 gate, a new timeout-raced/generation-guarded lazy Stockfish search, and a third steppable reveal line with honest loading/error states — proving the client-search-per-reveal architecture before the MultiPV rewrite and panel rebuild build on top of it.**

## Performance

- **Duration:** ~25 min
- **Completed:** 2026-07-26
- **Tasks:** 2
- **Files modified:** 14 (3 backend source, 1 backend test, 10 frontend source/test)

## Accomplishments

- Backend reveal response gains `played_in_game_move_uci` (mirrors `best_move_san`'s derivation inverted, same never-raise contract, same post-attempt 409 gate) — covers both normal (4-char) and promotion (5-char) UCI.
- `useTrainGradingEngine` captures the top MultiPV-1 line's `pv` on every search (previously parsed and discarded) and exposes `startGameMoveSearch(puzzleFen, gameMoveUci)`, racing the underlying search against `TRAIN_GRADING_TIMEOUT_MS` and rejecting a result whose generation was superseded before it becomes observable.
- `TrainLineStepper` gains additive `title`/`evalLabel` heading props reusing the existing motif-heading render slot.
- `TrainReveal` dispatches the new search once the reveal lands and renders a third "Played in game" steppable line with a live white-POV eval, cycling through honest `idle`/`loading`/`ready`/`error` states — never a stored server eval/line as a fallback on failure.

## Decisions Made

- A superseded `startGameMoveSearch` never resolves through the hook's normal bestmove path — the single-Worker stop/queue serialization silently discards the stale `pendingRef` on the termination echo, so it can only ever settle via the `TRAIN_GRADING_TIMEOUT_MS` race. This is the intended behavior (matches `gradeMove`'s own contract), not a gap; documented in the hook and pinned by a regression test that supersedes an in-flight search and asserts it still eventually rejects rather than resolving stale data.
- The non-ready game-move-box states (loading/error/idle-with-SAN) share one `gameMoveTitle` JSX value instead of duplicating the header markup three times.
- The promotion-UCI backend test uses a custom hand-verified pawn-race PGN (`1. h4 a5 2. h5 a4 3. h6 a3 4. hxg7 axb2 5. gxh8=Q bxa1=Q`) rather than extending the shared `_PGN` Ruy Lopez fixture, which never reaches a promotable position.
