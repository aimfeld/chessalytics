<objective>
Close the loop: record a solve, advance the ladder, and hand back the reveal — plus the settings
surface that owns the day-boundary convention.

Purpose: POOL-08 makes the pool actually move (mastery and parking only exist once results are
recorded), and POOL-10's second half is the reveal gate that keeps the answer key out of reach until
the attempt is in. `PUT /train/settings` is where the browser's IANA timezone lands, which is the
input D-06's whole day-boundary convention runs on and Phase 191 must reuse verbatim.

Output: `record_solve` / `reveal_for_puzzle` / settings CRUD in `train_repository.py`; three new
handler groups in `routers/train.py`; the solve, reveal and settings schemas; endpoint tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → `POST /sessions/{id}/solve` | Untrusted `session_id`, `position`, `guess`, `played_move`, `correct_move` |
| client → `GET .../reveal` | Untrusted `session_id` and `position`; the response is the answer key |
| client → `PUT /settings` | Untrusted IANA timezone string that drives every future due-date computation |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-189-16 | Elevation of Privilege | `record_solve` / `reveal_for_puzzle` | high | mitigate | Both resolve the row with `user_id` from `current_active_user` in the WHERE clause; a foreign `session_id` returns 404, covered by `test_solve_foreign_session_404` and `test_reveal_foreign_session_404` |
| T-189-17 | Information Disclosure | reveal before attempt | high | mitigate | `solved_at IS NULL` returns 409 with no answer-key fields in the body; asserted by `test_reveal_409_before_attempt` |
| T-189-18 | Tampering | client-asserted `correct_move` | medium | accept | Client-side grading is the settled design (SEED-037); v1 has no leaderboard or competitive integrity, so a self-inflicted false verdict harms only that user's own schedule. `correct_guess` is NOT client-assertable (P-02) |
