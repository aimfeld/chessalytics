<objective>
Prove the whole Train architecture end to end on one puzzle, then lock the grading budget with real measurement.

This plan lands the tracer slice: a real user reaches `/train`, starts a session against the shipped Phase 189 endpoints, studies a locked board, commits a binary guess (SOLV-01), plays exactly one move, and gets a client-side graded verdict (SOLV-03) recorded via the solve POST. Everything is production code — the later plans expand outward from this slice, they do not replace it.

Purpose: the two genuinely unproven things in this phase are (a) that fully client-side WASM grading with no server answer key actually closes the loop, and (b) what search budget that grading needs. Both are settled here, on the executor's best context, before any expansion work is committed on top.

Output: `/train` route reachable and gated, `trainApi` + typed payload mirrors, a session-scoped grading engine, a working one-puzzle solve loop, and a measured grading movetime constant.
</objective>
