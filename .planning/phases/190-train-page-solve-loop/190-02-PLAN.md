<objective>
Close the two payload gaps Phase 189 deliberately left open, additively and without reopening POOL-10.

`TrainPuzzle` gains the move that produced the position (arrival data, not answer data) so the solve screen can satisfy SOLV-02's "opponent's last move animated + highlighted". `PuzzleRevealResponse` gains the stored best line as a SAN list — strictly post-attempt behind the existing 409 gate — so SOLV-05's steppable best line has a source on puzzles that carry no tactic tag.

Purpose: these are the only backend changes in the phase. They are small, additive, and must not become a re-architecture of the Phase 189 schema.

Output: two new response fields, one shared PGN-replay helper, one promoted PV-to-SAN helper, backend tests including an explicit POOL-10 key-set guard, and the mirrored TypeScript types.
</objective>
