Build `TrainLineStepper.tsx`: a small, single-chain stepper with no branching, no forking, and no deletion.

Props: a SAN move array, a starting FEN, an optional motif key, an optional depth, and an optional board id. Internal state is a single current index into the array. Deriving the position at each step means replaying the SAN tokens from the starting FEN with chess.js — mirror the replay the existing tactic-lines consumer already performs, do not write a second replay idiom.

Rendering: the reveal's existing board is the stage (D-08/D-09 mandate one interactive board), so the stepper drives the position it is given rather than mounting a second board — expose the derived FEN through a callback the reveal wires to the board. If the component does mount its own board for any reason, it must pass a distinct board id so square test ids cannot collide.

Controls: previous and next buttons (`data-testid="btn-train-step-prev"` / `btn-train-step-next`), each `aria-label`led since they are icon-driven, disabled at the respective ends of the sequence. A move list rendered as selectable tokens, where the index is the array position — one token is one ply. Never index into the SAN string by character. Above the list, when a motif is supplied, render the motif's display label via the shared label helper and the depth via the shared depth-badge helper; motif comparison anywhere in the component uses the raw motif key, never the display label.

The component handles a one-element array (both controls disabled, the single move shown) and must never be rendered with an empty or null array — the caller is responsible for not rendering it, and the component's props type should make the array non-optional so that contract is a type error rather than a runtime empty state.

A deep line may run many plies. Cap the rendered token list's height and let it scroll within its own block rather than growing the reveal card unboundedly; the board and the controls stay fixed. State the cap as a named constant.

Write `TrainLineStepper.test.tsx`: stepping forward and backward changes the derived FEN in the expected order; prev is disabled at index zero and next at the last index; a one-element line disables both; clicking a token at index k derives the same FEN as stepping forward k times; the motif label rendered is the display form of a raw motif key; a long line renders all its tokens inside the scrolling block without the container growing past the cap.
