<objective>
Land the phase's tracer slice: one complete, verified, shippable improvement measured end
to end. Capture the pre-phase main-thread baseline, ship the single-pass UCI-keyed policy
conversion with its parity guard, re-measure against the captured baseline, and retire the
transient prototype so the baseline pass measures shipped code.

Purpose: JANK-01's real hot spot is `maiaQueue.ts`'s per-SAN `sanToUci` loop, not
`maskAndSoftmax`. chess.js's `Move` constructor re-runs full legal-move generation per move
to produce SAN, so the current path is O(n²) plus two FEN serializations per candidate plus a
third full `new Chess(fen); chess.move(san)` round-trip per key. A new UCI-keyed function
collapses that to exactly one `_moves({legal:true})` call.

Output: `maskAndSoftmaxUci` in `maiaEncoding.ts`, `maiaQueue.handleResult` rewired onto it,
parity tests including an underpromotion fixture, `194-BASELINE.md` with before/after
measurements and the bit-identity evidence, and `engine-mainthread-cost.mjs` reduced to a
single measured path that calls the shipped function.
</objective>
