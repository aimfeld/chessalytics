<objective>
D-15 step 1 — the instrumentation prerequisite. The harness cannot currently measure the
policy/grade wall split at all (U-03): `maiaInferenceStats` counts `session.run` calls with no
companion time accumulator, and `grade_cpu_ms` is aggregate CPU across four Stockfish procs.
And the harness does not serialise Maia the way the app does (U-05), so a speedup measured on it
would describe a scheduling regime production never runs.

This plan adds all three instruments — a `maia_cpu_ms` accumulator, a `maia_peak_inflight` gauge,
and an opt-in app-faithful Maia FIFO — emits them as TSV columns, and corrects the stale
`SearchBudget.concurrency = 1` header claim in the same edit (D-03).

Purpose: DISPATCH-02's re-baseline (198-03) and its exit decision (198-04) turn on exactly the
Maia-versus-tree-overhead split this instrumentation resolves. Nothing downstream is trustworthy
without it.
Output: instrumented `calibration-providers.mjs`, a plain-Node check script, and widened TSV
columns on `engine-grading-depth-ab.mjs`.
</objective>

`(fen, elo, side) => nodePolicy(session, ort, fen, elo, side)` — every existing caller that
passes three arguments keeps the current non-serialized path, which is what keeps existing
calibration sweeps unaffected (D-03).

`maiaQueue.ts`'s `dispatching` gate: a pending array, a `dispatching` boolean, and a
`processQueue()` that returns immediately while `dispatching` is true, otherwise shifts the head
request, sets `dispatching`, calls `nodePolicy(...)`, and — in BOTH the fulfillment and the
rejection handler — clears `dispatching`, settles that request, and re-enters `processQueue()`.
The rejection path resolves with an empty object rather than rejecting: this module's own
providers-degrade-by-resolving-never-hanging convention. Do not add Sentry (this file has no
telemetry sink) and do not add same-FEN batching — `runMaia`'s existing `(fen, elo)` memo already
collapses duplicates, so batching would be redundant machinery whose only effect is to make the
FIFO diverge from the property being mirrored.
