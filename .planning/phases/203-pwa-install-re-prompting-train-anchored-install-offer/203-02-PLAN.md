<objective>
Fix the three real defects in `useInstallPrompt` and make the install drawer a bounded,
re-offerable, structurally-non-interfering surface: a 14-day cooldown with a 3-attempt cap
replacing the permanent boolean veto, the captured `BeforeInstallPromptEvent` retained on
dismissal, `isStandalone` ORing `navigator.standalone`, suppression on all Train routes, and
the `?src=handoff` marker that survives Google SSO and overrides both.

Purpose: today a single tap on "Not now" burns the install offer forever and kills the
captured event for the rest of the SPA session, and an already-installed iOS user is shown
Add-to-Home-Screen instructions permanently. These are the phase's shipped-bug half — they
are verifiable in vitest, need no iPhone, and everything else builds on the widened hook.

Output: a pure cooldown resolver, a one-shot handoff marker module, a rewritten hook, a
route-aware banner, and the two greenfield test files RESEARCH.md flagged as Wave-0 gaps.
</objective>
