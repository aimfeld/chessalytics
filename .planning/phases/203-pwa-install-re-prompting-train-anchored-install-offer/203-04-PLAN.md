<objective>
Fill the two iOS-shaped holes: the `ios-tabbed` reminder slot that renders nothing today, and
the install-then-later-visit-then-permission two-session cliff that leaves an iOS user who
installed FlawChess with no path back to the reminder prompt.

Purpose: D-17 sequences this LAST and isolates it to one plan on purpose. The operator has no
iPhone and this branch ships unverified by design (SEED-134 amendment E, CONTEXT.md D-01) —
the answer arrives passively from whether iOS standalone devices appear in
`push_subscriptions` after deploy. Everything in Plans 01-03 is verifiable without an iPhone
and must remain shippable if this plan is later reverted. Every code path here therefore
fails safe: any unknown or unavailable iOS signal degrades to exactly today's behavior.

Output: the iOS install affordance with its synchronous intent write and honest two-step
instructions, and a standalone re-surface banner that routes the user to Train and clears
itself on subscribe or dismiss.
</objective>
