<objective>
Replace plan 01's five-row seed with the real sharp set: 200+ CC0 lichess positions selected
for motif variety in the 1000-1400 / short-PV band, each one confirmed genuinely sharp by an
offline Stockfish MultiPV-5 pass, committed as data.

Purpose: D-15 makes the server assert `puzzle_type = "sharp"` for every filler unconditionally.
Because D-12 excludes mates, "this position is sharp" is no longer provable from the theme
label — so a position with several genuinely fine moves would mark a correct "several" guess
WRONG. The offline verification pass is what makes that constant assertion true rather than
assumed. Sizing to 200 (not SEED-140's ~50) is what D-05 requires, since filler is now
unbounded in time rather than a one-week cold-start bridge.

Output: `scripts/gen_sharp_filler_set.py` (run once, never shipped or scheduled) and the
committed `app/data/sharp_filler_puzzles.csv` it produces, plus the data-integrity test that
holds the committed file to every D-12/D-13/D-18 constraint.
</objective>
