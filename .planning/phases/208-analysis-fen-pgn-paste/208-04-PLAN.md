<objective>
Give pasted games a route back: hidden from both Library tabs by default, revealed by an
explicit Library-scoped "Pasted" chip, and marked with a text badge on the card so they can
never be mistaken for a game the user played.

Purpose: D-11 makes the Library consistent with D-05 rather than an exception to it — pasted
games are frequently NOT the user's own (a broadcast game, a friend's PGN, a scouted
opponent), so they must not pollute stats or game history unless explicitly asked for. The
containment problem is real and specific: `FilterState` is a module-level store that survives
SPA navigation, so an opt-in expressed as a platform value would follow the user into
Openings, Endgames and Insights.

Output: `resolve_library_platforms` in `library_service`, an `include_pasted` wire param on
the five platform-filterable library routes, a `FilterState.includePasted` boolean, the
Library-only chip, and the card badge.
</objective>
