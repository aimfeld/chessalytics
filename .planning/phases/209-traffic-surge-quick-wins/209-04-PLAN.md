## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet → Cloudflare edge | New boundary: a third party now terminates TLS for site traffic and serves cached bytes. |
| Cloudflare edge → origin (Caddy) | New boundary: the proxied leg, whose TLS validation is governed by the SSL/TLS mode. |
| registrar (Swizzonic) → authoritative DNS | The delegation itself; whoever controls it controls every answer for the domain, including mail. |
