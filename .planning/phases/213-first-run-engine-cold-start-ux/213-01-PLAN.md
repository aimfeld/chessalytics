capability probe runs before any fetch, the Maia model is downloaded by an

analysis board (Plan 05).

**2. `frontend/src/lib/engine/engineAssetProgress.ts` (new) — D-01/D-04/D-07/D-11 foundation.**
A module-level singleton store, `useSyncExternalStore`-shaped, that outlives
every component (this is what satisfies D-07 on the consumer side; the fetch
itself lives in the worker). Export:
- `export type EngineAssetId = 'maia-model' | 'stockfish-wasm';` (a discriminated
  literal union, never bare `string`).
- `export const MAIA_MODEL_BYTES_FALLBACK = 45_683_686;` and
  `export const STOCKFISH_WASM_BYTES_FALLBACK = 7_295_411;` with a comment
  recording that these are the raw byte sizes verified live 2026-08-28 and are
  the defense-in-depth fallback for a missing/garbage `Content-Length`
  (213-RESEARCH.md Pitfall 3). Compose them into
  `ENGINE_ASSET_FALLBACK_BYTES: Record<EngineAssetId, number>`.
- `export const ENGINE_ASSET_LABEL: Record<EngineAssetId, string>` =
  `'maia-model'` to `'Maia model'`, `'stockfish-wasm'` to `'Stockfish engine'`.
  These are the D-10 asset names shown to the user.
- `export type EngineAssetStatus = 'idle' | 'unsupported' | 'downloading' | 'ready' | 'failed';`
  The full union ships now even though Plan 04 owns the `unsupported`/`failed`
  transitions and copy — the type must not change under later plans.
- `export interface EngineAssetsSnapshot { status: EngineAssetStatus; assets: Partial<Record<EngineAssetId, { loaded: number; total: number; done: boolean }>>; }`
  `Partial<Record<...>>` because `noUncheckedIndexedAccess` is on; narrow every
  read before use.
- `reportEngineAssetProgress(id, loaded, total)`: coerce defensively —
  `const safeTotal = Number.isFinite(total) && total > 0 ? total : ENGINE_ASSET_FALLBACK_BYTES[id];`
  and clamp `loaded` into `[0, safeTotal]`. Keep `loaded` **monotonic** per id
  (`Math.max` against the stored value) so two sources reporting the same asset
  cannot make the bar go backwards. Sets `status` to `'downloading'` unless it
  is already `'ready'`. Notifies listeners.
- `markEngineAssetReady(id)`: sets that id's `done: true` and `loaded = total`,
  writes the localStorage seen-flag (below), recomputes `status` to `'ready'`
  when every registered id is done. Notifies.
- `markEngineAssetsUnsupported()` and `markEngineAssetFailed(id)`: set `status`

  for the SIMD-probe path.

- `export const ENGINE_ASSET_SEEN_KEY_PREFIX = 'flawchess.engineAsset.seen.';`
  and `hasSeenEngineAsset(id: EngineAssetId): boolean` reading
  `localStorage.getItem(ENGINE_ASSET_SEEN_KEY_PREFIX + id)`, wrapped in

**3. `frontend/src/hooks/useEngineAssets.ts` (new) — D-10/D-11 read model.**
