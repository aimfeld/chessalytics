<objective>
Cut the persona-avatar bundle payload from ~794 KB to roughly 120 KB by
shipping 128x128 WebP variants instead of the 512x512 masters, and make every
avatar `<img>` load lazily. The 512x512 masters are kept (not deleted, not
overwritten) in a directory outside Vite's bundle glob, and the generation
script gains an offline mode that rebuilds every shipped variant from them.

Fully independent of the engine cold-start work — this is the second half of
the originating user report ("persona images loaded slowly").

Purpose: the /bots grid stops shipping ~9x-oversampled art to a phone.
Output: a source/bundle split in `frontend/src/assets/`, a two-size generation
script, and lazy `<img>` loading at all three avatar render sites.
</objective>
