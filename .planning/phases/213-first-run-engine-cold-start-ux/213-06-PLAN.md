<objective>
Make the engine asset download one unconditional bundle. Today the required-asset
set is a function of the persona's search blend: a blend-0 rung downloads Maia
alone (45.7 MB), a blend>0 rung downloads Maia plus Stockfish (53.0 MB). That
split buys ~16% off the cold-start wait for the low rungs and costs a conditional
in four places — the gate predicate, the gate component, the bot bring-up effect,
and the retry seam.

The user reviewed the trade during UAT test 19 and locked the other side of it:
always download both.

Purpose: G-213-19b. It also unblocks 213-07 — the analysis board's gate must be
written against a required-asset set that does not depend on a persona, because
the analysis board has no persona.
Output: a zero-argument `requiredEngineAssets()` / `engineGateRequired()`, an
`EngineReadyGate` with no `blend` prop, and a `useBotGame` with no blend branch in
either its bring-up effect or its retry seam.
</objective>
