<objective>
Turn `compose_and_materialize_session` into a three-stage composition pipeline so it stops
breaching the branch limit, and prove with a mutation test that the extracted seam is really
covered.

Purpose: this is Train's session composer — 317 raw lines carrying decisions from at least
five separate phases (the D-10 completed-session reuse window, the Phase 206 sharp-filler
shortfall rule, the D-02 herring cap, the D-09 deterministic seeded shuffle, and the D-06/D-07
warm-up discriminant). RESEARCH flags this file as a thin test seam: not one private helper is
imported by name in its tests, so a newly extracted helper could be reached only transitively
and a defect in it could pass unnoticed. The mutation proof is therefore mandatory here, not
optional.

Output: `compose_and_materialize_session` inside `max-branches = 12` as a named-stage
pipeline, the file's `per-file-ignores` entry deleted, an unchanged session composition, and a
recorded mutation proof.
</objective>
