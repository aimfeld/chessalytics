<objective>
Ship cross-origin isolation site-wide and let the Maia worker use the wasm threads it
unlocks.

Purpose: FlawChess ships no COOP/COEP headers today, so `self.crossOriginIsolated` is
false and onnxruntime-web is pinned to one wasm thread while maiachess.com runs four.
On the reference box that is the difference between a ~1,731 ms and a ~912 ms 21-rung
ladder at 1.27.0 (`219-MEASUREMENTS.md`). The Phase 136 rationale for withholding the
headers ("severs the Google OAuth popup") is obsolete: the OAuth flow is a full-page
redirect, which COOP cannot break.

Output: COOP/COEP on every document response in prod, dev and preview; CORP on the Umami
host plus a `crossorigin` attribute so the script also loads before that reaches prod; an
inverted CI guard; a fail-safe thread-count formula on both worker session paths; and a
browser UAT run covering all six D-10 legs.

Decisions implemented by this plan:
- D-05: COOP `same-origin` plus COEP `require-corp` on every document response, in the Caddy `flawchess.com` header block and in `server.headers` / `preview.headers` (Tasks 1 and 2).
- D-06: CORP `cross-origin` on the `analytics.flawchess.com` vhost, plus the sanctioned `crossorigin` attribute at the source so the script also loads pre-deploy; `credentialless` is never used (Task 2).
- D-07: the CI guard is inverted to assert presence and fails when either header is missing; the WASM MIME check stays (Task 2).
- D-08: `chooseWasmThreadCount()` replaces the hardcoded single thread at both session-init sites, with `MAIA_MAX_WASM_THREADS` of 4 and `self.crossOriginIsolated` as the fail-safe (Task 1).
- D-09: every source citation of the retired single-threading rationale is updated; Stockfish stays single-threaded and its multi-thread build is captured as a seed (Task 2).
- D-10: all six real-browser legs are verified with claude-in-chrome where possible; hardware-only legs are listed as HUMAN-UAT (Task 3).
- D-14: this plan is the second of the three sequential squash-merges and runs the full pre-merge gate plus `npm run build` (Task 4).
- D-15: measured, not asserted — the wave-2 reference-box browser numbers are recorded against their targets (Task 3).
</objective>
