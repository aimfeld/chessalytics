# Quick 260813-o4s: Swap Move/Capture sound clips + correct README attribution

Replace the two most-heard bot-play clips (`Move`, `Capture`) with sounddino
one-shots chosen by the user, and rewrite the README sound-asset section so it
describes what is actually vendored.

## Background

`frontend/public/sound/` currently holds lila `sfx` clips (Enigmahack, AGPLv3+).
Measured against lichess's `standard` set (which lila's `COPYING.md` lists under
"Exceptions (non-free)", so it cannot be shipped), the `sfx` clips are much
longer and brighter, which is what made them feel muddy:

| clip | effective duration | spectral centroid |
|------|-------------------|-------------------|
| standard_Move (reference) | 40.2 ms | 889 Hz |
| sfx_Move (current) | 96.7 ms | 2764 Hz |
| standard_Capture (reference) | 62.9 ms | 1344 Hz |
| sfx_Capture (current) | 330.7 ms | 5053 Hz |

Replacements were cut from sounddino.com chess field recordings by onset
detection (strongest well-isolated transient, short window, fade-out, normalize):

| new clip | source recording | effective duration | centroid |
|----------|-----------------|-------------------|----------|
| Move | `the-sound-of-a-move-in-a-game-with-one-piece-chess.mp3` | 64.8 ms | 1263 Hz |
| Capture | `a-series-of-sounds-with-the-move-of-a-playing-piece-the-horse-walks.mp3` | 67.0 ms | 1717 Hz |

**Licensing decision (user's call, 2026-08-13):** sounddino.com publishes no
license or terms page — only the category-page claim "royalty-free, no
attribution, free for commercial use". That is weaker than the per-file explicit
grant normally required for redistribution from a public AGPL repo. The user
accepted this as a risk-based tradeoff: low likelihood of a claim over a 40 ms
click, and a trivial swap as the remedy. The README must therefore record the
exact source URL and retrieval date so a future replacement is mechanical, and
must NOT assert a license we cannot substantiate.

## Scope

`sounds.test.ts` need no edit. `frontend/dist/` is gitignored (build artifact).
