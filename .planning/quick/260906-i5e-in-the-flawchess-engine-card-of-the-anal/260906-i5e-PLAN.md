# Quick 260906-i5e: FlawChess card header shows a running node count

In the FlawChess Engine card of the analysis board, show a running node count (like the Stockfish card's "Depth N"). Header reads `FlawChess, {elo} ELO, {n} Nodes`.

## Findings

- `useFlawChessEngine` already returns `nodesEvaluated` (from `EngineSnapshot.nodesEvaluated`, reset to 0 on every FEN change, throttled per `onSnapshot` tick). No search-core change needed.
- The card lives in `frontend/src/components/analysis/AnalysisTabs.tsx` (`FlawChessCard`), fed by `flawChessCardProps` in `frontend/src/pages/Analysis.tsx`.
- Stockfish card gates its suffix on `depth > 0`; mirror that with `nodesEvaluated > 0`.
